## Agent skills

### Issue tracker

Jira project `LAB` (micelabs.atlassian.net) holds one Epic per feature; beads (`bd`)
holds the tickets, per the user-level default. See `docs/agents/issue-tracker.md`.

### Triage labels

The default five (`needs-triage`, `needs-info`, `ready-for-agent`, `ready-for-human`,
`wontfix`), applied as Jira labels. See `docs/agents/triage-labels.md`.

### Domain docs

Single-context: `GLOSSARY.md` + `docs/adr/` at the repo root. See `docs/agents/domain.md`.
